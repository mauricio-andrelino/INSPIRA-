# 📱 Inspira+

Aplicativo mobile desenvolvido com React Native, com o objetivo de apresentar frases motivacionais de forma aleatória, incentivando o usuário diariamente.

## 🚀 Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- StyleSheet

## 📋 Pré-requisitos

Antes de executar o projeto, tenha instalado:

- Node.js
- npm
- Expo Go no celular

## ⚙️ Como executar o projeto

**1. Clone o repositório:**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

**2. Entre na pasta do projeto:**

```bash
cd inspira-mais
```

**3. Instale as dependências:**

```bash
npm install
```

**4. Inicie o aplicativo:**

```bash
npx expo start
```

**5. Abra no celular:**

- Instale o aplicativo Expo Go.
- Escaneie o QR Code exibido no terminal.
- Aguarde o aplicativo carregar.

## ✨ Funcionalidades

- Exibição de frases motivacionais.
- Sorteio aleatório de frases.
- Alteração automática das imagens.
- Interface simples e interativa.
- Botão para gerar novas inspirações.
